Part 3: Rings and Fields

Companion to Paulin's Introduction to Abstract Algebra

In Part 2, we isolated a single combining operation to build Groups. But the integers ℤ possess two natural operations: addition and multiplication. A Ring is an abstract set equipped with both, bound together by a single crucial law.

4.1 Basic Definitions

Fundamental Definition
A ring is a set R with two binary operations, + and ×, such that:
1. R is an Abelian group under addition.
2. R is a monoid under multiplication (associative, has identity 1).
3. + and × are related by the distributive law: a × (b + c) = (a × b) + (a × c).

The distributive law is what makes a ring a single unified structure, rather than two unrelated operations living on the same set. We can visualize it as area.

Definition
A non-zero element a is a zero-divisor if ab = 0 for some non-zero b. A commutative ring with no zero-divisors is an integral domain. If every non-zero element has an inverse, the ring is a field.

4.2 Ideals and Quotient Rings

In group theory, we collapsed groups using Normal Subgroups. In ring theory, the structure that lets us cleanly collapse a ring is called an Ideal. An ideal I is a sub-group under addition that perfectly "absorbs" multiplication by any element of the ring R.

The ideal (a) is the set of green multiples. Click Multiply to take an element x inside the ideal, multiply it by any integer r, and watch it absorb back inside.

4.8 Principal, Prime, and Maximal Ideals

Because an ideal absorbs everything, we can form the quotient ring R/I. The properties of the ideal completely determine the properties of the quotient. If I is "prime", R/I has no zero-divisors (Integral Domain). If I is "maximal" (no larger proper ideal can contain it), R/I is a Field.

I is Prime <=> R/I Domain I is Maximal <=> R/I Field
Viewing the quotient ring R/I (which is ℤ/mℤ). In the integers, every non-zero prime ideal is automatically maximal, so both badges always light up together!
Where the picture lies
In finite integral domains (and quotients of ℤ), every Prime ideal is Maximal. In more complex rings (like polynomials in two variables), an ideal can be Prime without being Maximal—the first badge would light up while the second stays off.

4.4 Polynomial Rings

We can build rings out of things besides numbers. A polynomial is formally just an infinite sequence of coefficients where only finitely many are non-zero. Let's look at F[X], where the coefficients themselves come from a field F (like ℤ/5ℤ).

4.9 Factorisation in Integral Domains

We know how to find the Greatest Common Divisor in ℤ using the Euclidean Algorithm: repeated division with remainder. Miraculously, because degrees of polynomials act just like the absolute value of integers, the exact same algorithm works in F[X].

This allows us to classify rings into a hierarchy. Every Euclidean Domain (ED) guarantees Principal Ideals (PID), which in turn guarantees Unique Factorization (UFD).

Atoms of F[X]

In the ring of integers, the "atoms" are primes. In a polynomial ring F[X], the atoms are irreducible polynomials. But unlike ℤ, the "periodic table" of atoms in F[X] changes drastically depending on which field F you use for the coefficients!

Toggle the base Field. In ℂ, every atom is degree 1. In ℝ, atoms can be degree 1 or 2. In ℚ, there are atoms of every possible degree (a fact proved by Eisenstein's Criterion).

This wild complexity in ℚ[X] is the seed for Part 4. The roots of these irreducible polynomials generate new, higher-dimensional field extensions, leading us to Galois Theory.
