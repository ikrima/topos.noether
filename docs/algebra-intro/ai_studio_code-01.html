Part 1: The Structure of ℤ

Companion to Paulin's Introduction to Abstract Algebra

If you ask a mathematician what algebra is, you might get a response along the lines of: "Algebra is the abstract encapsulation of our intuition for composition."

By composition, we mean the concept of two objects coming together to form a new one. The most fundamental example of composition is something you've known since childhood: adding two numbers. But to see the algebra, we need to separate the act of combining from the numbers themselves.

Throughout this series, we will study sets equipped with combining machines like this. But first, we need a precise way to talk about sets and the maps between them.

1.2 Sets and Functions

Definition
A map (or function) f from a set S to a set T is a rule which assigns to each element of S a unique element of T.

When analyzing functions, we care deeply about whether they compress information (mapping multiple inputs to the same output) and whether they cover the entire target space.

  • f is injective if no two elements of S map to the same element of T.
  • f is surjective if every element of T is hit by some element of S.
  • If f is both injective and surjective, we say it is bijective. Intuitively, this gives a perfect matching, allowing us to reverse the arrows.

1.3 Equivalence Relations

Within a set, it is sometimes natural to talk about different elements being related. For example, in ℤ, we could say two numbers are related if they are both odd or both even. An equivalence relation formalizes this by demanding the relation be symmetric, reflexive, and transitive.

Definition
Let ~ be an equivalence relation on a set S. The equivalence class containing x is the subset [x] = {y ∈ S | y ~ x}. A collection of subsets forms a partition of S if they are non-empty, pairwise disjoint, and their union is S.

We declare two numbers equivalent if they leave the same remainder when divided by m. What happens to the set of integers when we apply this relation? They collapse into distinct, non-overlapping groups.

Slide m to partition the set {0, ..., 11}. Elements with the same remainder mod m snap to the same colored block.
Where the picture lies
The statement "an equivalence relation is exactly the same thing as a partition" is exact. Every valid equivalence relation corresponds to exactly one way of grouping the set into disjoint, colored blocks.

2. The Structure of ℤ

Let us look closer at the integers. Under addition, ℤ has a special property: it can be generated entirely by the number 1.

Click +1 or -1 to walk across the integers. Every element can be attained by successively adding 1 (or -1) to itself.

By contrast, there is clearly no single generator for ℤ under multiplication. The multiplicative structure is far more rigid. Instead of being generated by one element, integers break down into a unique collection of unbreakable atoms.

Fundamental Theorem of Arithmetic
Every positive integer greater than 1 can be written as a product of primes. Such a factorization is unique up to ordering.

2.3 Congruences and ℤ/mℤ

We've partitioned ℤ into remainder classes modulo m. We call this set of residue classes ℤ/mℤ. We can define addition and multiplication on these classes by simply adding or multiplying their representatives. Geometrically, this turns the infinite number line into a closed loop: a clock.

However, while addition on ℤ/mℤ always behaves nicely, multiplication hides a surprise. In normal arithmetic, two non-zero numbers never multiply to zero. Let's see if that holds on the clock.

Definition
In a ring, a non-zero element a is a zero-divisor if there is some non-zero b such that a × b = 0. An element is a unit (has a multiplicative inverse) if there is some x such that a × x = 1.

In the figure below, the dial represents the elements of ℤ/mℤ. The table on the right is the Cayley table for multiplication modulo m.

This means ℤ/pℤ is a field if and only if p is prime. This interplay between geometry (the dial) and grid structure (the table) forms the foundation of Group Theory, which we tackle in Part 2.
