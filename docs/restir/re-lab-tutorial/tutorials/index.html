Tutorials

Lessons. You follow along, something happens, and you end up able to do a thing you could not do before. Start here if you have never rendered anything.

They are meant to be read in order; each assumes the one before it.

Render your first image
Install, render the Cornell box, and watch noise fall as you raise the sample count.
Watch a scene lower
Follow one scene through every level of the pipeline, as text you can diff. No GPU, no display, a few seconds.
Catch a biased estimator
Render the same scene two ways, fail to tell them apart by eye, then measure the one that is wrong.
Inspect a single pixel (a display)
Click a pixel in the GUI and read the exact path that produced it.
