Lifecycle#

Engine(scene, prefer_gpu=False, init=True)

_build() is where the Taichi ownership discipline lives, and the order is forced:

self._fb = ti.FieldsBuilder()                      # per-engine builder, NOT the default root
self.scene_device = SceneDevice(self.scene, builder=self._fb)
self.plan = compile_graph(assemble_di_graph(self.scene), self.scene_device,
                          make_field=lambda d: make_field(d, self._fb))
self._snode_tree = self._fb.finalize()
self.scene_device.upload()                         # only after finalize
self._advance = self._make_advance()
self._materialize()                                # touch every field on this thread
self.reset()

Contract — building an Engine costs ~5s. Taichi recompiles every kernel per engine, because each owns its own FieldsBuilder. Never construct engines in a loop; use the setters below. The validation harness threads an engine= parameter through for exactly this reason.

Contract — close() releases the SNode tree. Taichi has a finite number, so a GUI strategy switcher would exhaust them otherwise.

rebuild(scene=None)    # close() + _build(); needed only for topology changes
close()

Setters — no recompile, all chainable#

set_camera(cam)    set_exposure(ev)    set_aov(name)
set_seed(seed)     set_bias_mode(mode) set_reproject(on)

set_bias_mode accepts "naive" | "mis" | "pairwise-mis" or a BiasMode. Each setter rewrites self.scene through the with_* IR edits and re-points ctx.scene, so the two never diverge.

The history roll — _make_advance#

Returns a @ti.kernel, or None when the plan has no reservoirs. Python cannot swap field references because the pass closures captured them at build time, so the copy happens on device:

gi   = int(self.scene.integrator.strategy) == int(Strategy.RESTIR_GI)
src  = "reservoir_temporal" if gi else "reservoir_curr"   # ! GI rolls PRE-spatial
@ti.kernel
def advance():
    for i in range(n):
        prev[i]      = curr[i]
        hits_prev[i] = hits[i]

This is the device twin of core/render._render_restir's rollover and must not drift from it. The reasoning, and the numbers, are in 02-core.

Two distinct resets#

reset()                                  # zero_persistent(): accumulator AND reservoirs
reset_accumulation(restart_sequence=True)  # only radiance_accum and moment2

Contract — reset_accumulation is the methodological core. ReSTIR's claim is about a single warm frame, and consecutive frames are correlated through the reservoirs, so comparing accumulated means understates ReSTIR — it can even lose to plain RIS. Variance must be measured per frame.

Contract — clearing the accumulator must not rewind the RNG. restart_sequence=False exists for exactly one case: a reprojecting camera drag, where the image is cleared every frame. Rewinding the sample counter would hand every drag frame the same sub-pixel jitter and — because sample_light_point(li, u, v) is deterministic — literally the same M points on the same M lights, so the canonical stream stops contributing new information the instant the drag begins.

Hence two counters that coincide everywhere except that path:

PropertyMeaning
Engine.sppsamples in the accumulator
ctx.spp_indexthe RNG sample counter

Cooking and outputs#

render_sample(only=None)      # plan.run(ctx, only) -> _advance() -> record prev_camera -> bump

Contract — the thread split. The main thread owns ti.init and all field allocation. The worker only runs an already-compiled plan. App._rebuild(scene) constructs the new Engine(scene, init=False) on the main thread, hands it to the worker, and only then calls old.close().

Because an open FieldsBuilder invalidates kernel launches anywhere, a rebuild must park the worker — block until it confirms it is idle — before allocation begins. Asking it to freeze is not enough; the rebuild has to know it has stopped.

Command enum: CAMERA ENGINE EXPOSURE AOV BIAS REPROJECT SPP_CAP RESTART FREEZE CAPTURE SNAPSHOT STOP. Camera commands are coalesced.

Camera moves branch on reprojection — reset_accumulation(restart_sequence=False) when ctx.reproject, else a full reset().

The CLI — pt/cli.py (637 lines)#

argparse with set_defaults(func=cmd_*). A shared common(p, spp_default=None) installs the scene-override flags, and one funnel applies them:

_load(args)   # entirely through SemanticIR's immutable edits

so every subcommand has identical override semantics and nothing mutates a scene in place.
