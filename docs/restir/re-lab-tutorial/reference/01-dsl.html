pt/dsl/ — the front end

Read, macro-expand, analyze, elaborate, the IR, the writer, the error catalog.

Source: docs/architecture/reference/01-dsl.mdinformation-oriented

Text to SemanticIR in four transforms. ~2,020 lines, the largest single layer, and roughly the part a Lisp host would hand you free — see porting-to-racket.md.

read — reader.py#

Hand-written, not a library. One _TOKEN regex (ws / comment / open / close / str / kw / num / sym) and a recursive-descent _parse.

read_all(source: str, src_name: str = "<string>") -> list
read_one(source: str, src_name: str = "<string>")

Form types, each carrying a Span:

FormFieldsSurface
Listitems, span(...) — a call or tag
Vecitems, span[...] — a tuple
Mappairs, span{...} — a record
Symvalue, spanbare symbol
Kwvalue, span:keyword
Numvalue, is_int, spannumber
Str, Bool, Nilvalue, spanliteral
@dataclass(frozen=True)
class Span:
    src: str; start: int; end: int; line: int; col: int

Span is a half-open [start, end) with a 1-based line and 0-based column, and .merge() / .render() — the latter prints the source line with a caret run.

Contract. Commas are whitespace. ; starts a comment. Duplicate map keys and odd-length maps are read errors (ReadError).

Why it is hand-written. A stock EDN reader gives you no spans, and spans are the whole basis of the diagnostics below. This is the single sharpest argument for the Racket port: syntax/parse provides exactly this for free.

macro-expand — macro.py#

expand_all(forms: list, source: str) -> list

Collects defmacro forms, then expands every remaining top-level form to a fixpoint, applicative order, depth-capped at MAX_EXPANSION_DEPTH = 64.

Builtins (BUILTIN_MACROS):

FormExpands to
(cornell-walls) / (cornell-walls :white :red :green)5 wall quad maps
(cornell-light) / (cornell-light :lamp)the emissive ceiling quad
(cornell-box)walls + light, as one geometry vector
(concat [a b] [c])[a b c] — lets macro output compose with literals

Box dimensions are module constants: CORNELL_W = 556.0, CORNELL_H = 548.8, CORNELL_D = 559.2 (millimetres; the room spans x∈[0,556], y∈[0,548.8], z∈[0,559.2] and opens toward −z, where the camera sits).

User macros: (defmacro name [params] body).

Contract — span inheritance. Synthesized forms inherit the call site's span (the Clojure default); substituted arguments keep their own. This is what makes an error inside a macro expansion point at the user's code rather than at the macro body.

analyze — analyze.py#

analyze(forms: list, source: str, src_name: str = "<string>") -> SceneAST

Shape checking against closed key sets. An unknown key is a hard error (UNKNOWN_KEY), not a warning — with a did_you_mean suggestion.

elaborate — elaborate.py#

elaborate(ast: SceneAST, source: str = None) -> SemanticIR

Five named jobs:

JobWhat it does
RESOLVENames → dense integer ids, in source order
DEFAULTFill omitted keys
NORMALIZEeye/look-at/up/fov → an orthonormal basis + tan_half_fov + aspect
STITCHLight ↔ prim mutual back-references: prims[gi].light_id = len(lights)
EXPAND:light-sampling → the Strategy enum

Contract — source-ordered indices. _build_symbol_tables assigns ids in source order, and its docstring says the ordering is load-bearing: buffer layout and RNG stream assignment are a deterministic function of the source text. Reordering :geometry in a scene file changes the image. This is intended — it is what makes a render reproducible from the text alone — but it means index assignment is not an implementation detail.

Contract — camera basis. right = normalize(cross(forward, up)), then up is re-orthogonalized. :up parallel to the view direction is DEGENERATE_CAMERA.

Diagnostics — errors.py#

@dataclass(frozen=True)
class ElabError:
    code: str; message: str; path: tuple = (); span: object = None; hint: str = None
    def render(self, source: str = None) -> str

class Diagnostics:
    def err(self, code, message, path=(), span=None, hint=None) -> None
    def check(self) -> None            # raises ElaborationFailed if any
    @property
    def codes(self)

did_you_mean(name: str, candidates) -> str

Contract — accumulate, then raise once. Errors collect in a Diagnostics and surface together as a single ElaborationFailed, every one rendered with a caret. A scene with four mistakes reports four, not the first.

23 codes, grouped by elaboration phase (errors.py::ERROR_CATALOG):

5 — integrator + cameraMISSING_RIS_CONFIG MISSING_RESTIR_CONFIG DI_BOUNCE_CONSTRAINT GI_BOUNCE_CONSTRAINT GI_STRATEGY_UNSUPPORTED GI_BOUNCE_EXACTLY_TWO BAD_RESOLUTION DEGENERATE_CAMERA
top levelNO_LIGHTS NO_GEOMETRY

Three carry real semantics worth knowing:

  • INFINITE_AREA_LIGHT — an area light bound to a :plane has infinite area, so its pdf is zero everywhere. Caught at elaboration rather than producing NaNs.
  • LIGHT_GEO_REUSED — two lights on one geometry would make the emitter you can hit with a camera ray disagree with the one you sample for NEE.
  • GI_BOUNCE_EXACTLY_TWO — a path reservoir holds one reconnection vertex, and the GI candidate dimensions deliberately alias the path tracer's per-vertex draws so that M=1 without reuse reproduces the uniform two-bounce estimator sample for sample. Deeper paths turn that alias into a silent correlation. See 02-core.

SemanticIR — ir.py#

Frozen, resolved, SoA-friendly. Everything downstream consumes this and nothing else.

Immutable edits#

The only supported way to vary a scene. Used by the CLI's _load funnel, the shell, and the whole validation harness:

with_camera(cam)   with_exposure(ev)  with_tonemap(name)  with_seed(seed)
with_strategy(s)   with_ris(M, target)  with_bias(mode)   with_restir(**kw)
with_resolution(w, h)  with_spp(spp)   with_max_bounces(n)

Contract — which edits need a rebuild. with_resolution, with_strategy, with_max_bounces and toggling spatial reuse change the graph, so an Engine must be rebuilt. Seed, camera, exposure, AOV, bias mode and reproject reach the kernels as arguments and need only a setter. See 05-runtime.

writer — writer.py#

to_edn(ir: SemanticIR) -> str

The inverse of the front end, and its stated purpose is the property

elaborate(read(to_edn(ir))) == ir

pinned by a parametrized round-trip test over every scene in pt/scenes/, with ir_close handling float ULP. pt edn <scene> prints it.
