information-oriented

Captured from pt 0.1.0 by docs/site/capture_cli.py. Regenerate it after changing pt/cli.py.

usage: pt [-h] {render,gui,describe,edn,dump,flip,validate} ...

An introspectable Direct-Lighting / RIS / ReSTIR DI path tracer

positional arguments:
  {render,gui,describe,edn,dump,flip,validate}
    render              render an image headlessly
    gui                 launch the interactive shell
    describe            print the compiled execution plan
    edn                 print the scene as canonical EDN
    dump                dump every cooked buffer to .npy
    flip                perceptual (FLIP) difference between two images
    validate            run the correctness harness

options:
  -h, --help            show this help message and exit

usage: pt render [-h] [--res W H] [--strategy {uniform,ris,restir-di,restir-gi}]
                 [--M M] [--bounces BOUNCES] [--bias {naive,mis,pairwise-mis}]
                 [--seed SEED] [--gpu] [--spp SPP] [-o OUT]
                 [scene]

positional arguments:
  scene                 bundled scene name or path to an .edn file

options:
  -h, --help            show this help message and exit
  --res W H
  --strategy {uniform,ris,restir-di,restir-gi}
  --M M                 RIS candidate count
  --bounces BOUNCES     path depth (1 = direct lighting; restir-gi requires 2; deeper

  --bias {naive,mis,pairwise-mis}
  --seed SEED
  --gpu
  --spp SPP
  -o OUT, --out OUT

pt flip#

usage: pt flip [-h] [-o OUT] [--raw RAW] [--mode {auto,ldr,hdr}]
               [--tonemap {aces,reinhard,linear}] [--exposures EXPOSURES]
               [--start-exposure START_EXPOSURE] [--stop-exposure STOP_EXPOSURE]
               [--ppd PPD] [--distance DISTANCE] [--width WIDTH]
               [--monitor-px MONITOR_PX] [--match-resolution]
               reference test

positional arguments:
  reference             .npy linear radiance or .png sRGB
  test                  the image under test, same kind and shape

options:
  -h, --help            show this help message and exit
  -o OUT, --out OUT     write the magma error map here ('' to skip)
  --raw RAW             also save the raw [0,1] error field as .npy
  --mode {auto,ldr,hdr}
                        auto: HDR for .npy radiance, LDR for .png (default)
  --tonemap {aces,reinhard,linear}
                        tone curve for the HDR sweep, or for LDR from radiance
  --exposures EXPOSURES
                        stops in the HDR sweep (0 = derived from the reference)
  --start-exposure START_EXPOSURE
  --stop-exposure STOP_EXPOSURE
  --ppd PPD             pixels per degree (default: 67, the published viewing
                        conditions)
  --distance DISTANCE   metres to the display
  --width WIDTH         display width in metres
  --monitor-px MONITOR_PX
                        display width in pixels
  --match-resolution    treat the image as filling the display, rather than assuming a
                        4K monitor showing it 1:1

pt validate#

usage: pt validate [-h] [--res W H] [--strategy {uniform,ris,restir-di,restir-gi}]
                   [--M M] [--bounces BOUNCES] [--bias {naive,mis,pairwise-mis}]
                   [--seed SEED] [--gpu] [--spp SPP] [--ref-spp REF_SPP]
                   [--anchor-stride ANCHOR_STRIDE] [--stride STRIDE] [--budget BUDGET]
                   [--checkpoints CHECKPOINTS [CHECKPOINTS ...]] [--no-flip]
                   [--flip-maps DIR] [--ppd PPD] [--variance-trials VARIANCE_TRIALS]
                   [--warmup WARMUP] [--temporal] [--temporal-frames TEMPORAL_FRAMES]
                   [--magnify MAGNIFY]
                   [scene]

positional arguments:
  scene                 bundled scene name or path to an .edn file

options:
  -h, --help            show this help message and exit
  --res W H
  --strategy {uniform,ris,restir-di,restir-gi}
  --M M                 RIS candidate count
  --bounces BOUNCES     path depth (1 = direct lighting; restir-gi requires 2; deeper
                        is uniform only)
  --bias {naive,mis,pairwise-mis}
  --seed SEED
  --gpu
  --spp SPP
  --ref-spp REF_SPP
  --anchor-stride ANCHOR_STRIDE
                        pixel grid for closed-form anchors
  --stride STRIDE       pixel stride for the sign test (0 = derive from the reuse
                        radius); must exceed it or the test is skipped
  --budget BUDGET       equal-time seconds
  --checkpoints CHECKPOINTS [CHECKPOINTS ...]
  --no-flip             skip the perceptual (FLIP) section
  --flip-maps DIR       also write a magma FLIP error map per estimator
  --ppd PPD             pixels per degree for FLIP (default: 67)
  --variance-trials VARIANCE_TRIALS
                        independent seeds for the per-frame variance section (<2 skips
                        it)
  --warmup WARMUP       frames of reuse to run and discard before measuring (reuse
                        strategies only)
  --temporal            also test temporal reprojection over an A/B camera path
  --temporal-frames TEMPORAL_FRAMES
                        camera-path length for --temporal
  --magnify MAGNIFY     how far the history camera is dollied back for --temporal;
                        sets how many pixel footprints the reprojected point moves
