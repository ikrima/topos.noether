Run the test suites

Python, Racket, the markers that skip the slow and the graphical.

Source: docs/how-to/run-the-test-suites.mdtask-oriented

There are two of them — Python for the renderer, Racket for the port — plus a mutation run that tests the tests.

Set up#

python -m venv .venv && .venv/bin/pip install -e ".[dev]"

Python 3.10 or newer. The GUI needs a display; everything else runs headless.

Python#

.venv/bin/python -m pytest                    # everything, ~6 min
.venv/bin/python -m pytest -m "not slow"      # skip the high-spp statistical tests
.venv/bin/python -m pytest -m "not gui"       # no display available

Two markers are declared in pyproject.toml:

markerwhat it selects
slowhigh-spp convergence and bias tests — minutes each, and the reason a full run is ~6 minutes
guianything needing a DearPyGui viewport

Combine them when you are on a headless box and in a hurry:

.venv/bin/python -m pytest -m "not slow and not gui"

The ones worth running while you work#

.venv/bin/python -m pytest tests/test_kernels.py::TestRestirGiKernels -q
.venv/bin/python -m pytest tests/test_core.py -k reconnection -q
.venv/bin/python -m pytest tests/test_graph.py -q

The first is the reference-versus-kernel per-pixel diff — the fastest useful signal in the repository if you touched an estimator. tests/test_graph.py runs the whole graph suite against a FakeField with no GPU, so it is seconds rather than minutes; add graph tests there first.

Building an Engine costs about 5 seconds — Taichi recompiles every kernel per engine, because each owns its own FieldsBuilder. Never construct engines in a loop. Use Engine.set_seed(), set_camera() and set_bias_mode() to vary a run.

Racket#

raco test port/racket             # everything

No installation needed — the tests require by relative path. To make (require restir/rng) work from anywhere:

raco pkg install --link port/racket

Mutation testing#

port/racket/test/mutations.sh     # ~3 min

This deliberately breaks the port and checks that the conformance suite notices. Seventy mutations are caught; six are documented as not caught, with reasons.

It is not optional, and it is not decoration. It has already caught a broken harness — the script grepped for "failed" where raco test prints "failures", so eight real mutations were reading as passes — and on step 3 it found two defects a 55,184-value fixture could not see: EPS is unreachable through any render, and every quad in every bundled scene is a rectangle, so the dot(u, v) terms of the quad solve vanish identically.

The general form is worth keeping: a fixture generated from an implementation tests only the branches that implementation happens to take, and that set is smaller than it looks.

See Verify the Racket port for the full workflow, including how to record a mutation that is expected not to be caught.

The conformance guard#

python docs/architecture/conformance/verify_conformance.py

Checks this repository against its own frozen RNG vectors. Stdlib only — it is the one check that runs without a venv, because everything else depends on it.

The documentation#

python docs/site/build.py

Also stdlib only. It fails on a dangling cross-reference, an unsupported Markdown construct, or drift between docs/site/findings.json and ARCHITECTURE.md. See Build the documentation.

No linter#

There is none configured, and no formatter. Match the surrounding code.
